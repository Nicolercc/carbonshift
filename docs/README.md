# CarbonShift Docs

This folder is the shared directory for CarbonShift product, data, backend, API, and frontend handoff documents.

Start here:

- [Product, Data, and Frontend Direction](product-direction.md) defines the MVP, product principles, user experience, frontend stack, and phase plan.
- [Frontend Implementation Plan](frontend-implementation-plan.md) turns the product direction into explicit phases, commands, ownership, and acceptance criteria.
- [API Contracts](api-contracts.md) documents the Flask JSON API surface the Next.js frontend should use.
- [Backend Context](backend-context.md) explains what the backend currently owns and what the frontend should not reimplement.

The main idea is simple:

> Bigger map. Less text. More visual explanation.
